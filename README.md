# 仙剑奇侠传 · 三式战斗版 v1.0

> Windows x64 SDLPAL 战斗扩展版。

## 启动

1. 确认 `sdlpal.exe`、`SDL3.dll`、`run.cmd` 和原版游戏数据在同一目录；
2. 双击 `run.cmd`，或直接运行 `sdlpal.exe`；
3. 默认 `LaunchSetting=0`，会直接进入游戏。

日志：`sdlpal.log`  
配置：`sdlpal.cfg`

## 主要内容

- 三式 A/B 行动条战斗；
- 每个角色、每个仙术独立熟练度；
- 法宝系统：3 槽、品质、词条、法宝囊、分解、灵尘；
- 新仙术五靈鎮嶽：新游戏由阿奴获得，李逍遥旧存档保留；
- 敌方 `五維↓`、我方武/防/速/運/靈箭头显示；
- 战斗中按 **5** 查看完整状态面板；
- 整体战斗速度为原来的 0.5 倍；
- 普通小怪 1/3 概率掉落 1 件法宝。

## 基本操作

| 按键 | 功能 |
|---|---|
| 方向键 | 移动/选择 |
| Enter / Space | 确认 |
| Esc | 菜单/取消 |
| A / D / E / W / Q / F / S / R | 自动/防御/物品/投掷/逃跑/仙术/状态/重复 |
| 1~5 | 仙术分类 |
| 5（战斗中） | 战斗状态面板 |
| Home / End | 开发调试键，正常游玩不建议使用 |

法宝入口：

```text
Esc → 物品 → 法宝
```

## 存档

- 原版存档：`.rpg`
- 法宝与熟练度：`.dshs`
- 每个存档槽分别对应自己的 sidecar；
- 旧版 55 槽 sidecar 会自动迁移到 56 槽；
- 新 sidecar 不能被旧版本程序反向读取；
- 五靈鎮嶽：李逍遥旧存档保留，新游戏由阿奴获得。

## 已知限制

- 无图形启动器，配置通过 `sdlpal.cfg`；
- 可能出现控制台窗口；

- Home / End 为调试键，可能破坏正常流程。
